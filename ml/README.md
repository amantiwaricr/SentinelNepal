# ml/ — SentinelNepal machine-learning package

**Status: Phase 2 (not started).** This directory holds the `sentinel_ml` package: dataset
loading, preprocessing, training, evaluation, and the inference API that the backend and
collector import. It is the *only* place where feature engineering lives (see `AGENTS.md`).

| Path | Purpose |
|---|---|
| `sentinel_ml/` | Python package (Phase 2) |
| `data/` | UNSW-NB15 files, placed manually; git-ignored (see `data/README.md`) |
| `artifacts/` | Trained model files; git-ignored (see `artifacts/README.md`) |
| `reports/` | Evaluation reports generated by real runs (committed) |
| `tests/` | Unit tests using small synthetic fixtures, clearly labelled synthetic |

No model has been trained and no metrics exist yet.
